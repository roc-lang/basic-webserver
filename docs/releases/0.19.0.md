# basic-webserver 0.19.0

This release updates basic-webserver for Roc's latest compiler, restores
cross-platform Windows linking, and includes complete third-party notices in
release bundles. It also renames the public TCP connection type, so applications
using that API need a small source update when upgrading from 0.18.0.

## Upgrading from 0.18.0

Use Roc `nightly-2026-10-24-f6c6cfb` with this release. The platform and example
manifests pin that compiler version.

`Tcp.Stream` is now `Tcp.Connection`, because `Stream` is a builtin type in the
new compiler. Update type annotations and qualified method references:

```roc
# Before
send! : Tcp.Stream, Str => Try({}, _)
send! = |connection, text| Tcp.Stream.write_utf8!(connection, text)

# After
send! : Tcp.Connection, Str => Try({}, _)
send! = |connection, text| Tcp.Connection.write_utf8!(connection, text)
```

`Tcp.connect!` returns the renamed type. Existing method calls such as
`connection.write_utf8!(text)` continue to work. Connection ownership, automatic
cleanup, and read/write behaviour are unchanged. This public API rename is the
reason for the 0.19.0 version bump.

## Windows builds include their runtime inputs

The platform now supplies the MSVC startup code, runtime support, and import
libraries required by the new Roc linker. Every release-validation builder can
cross-build Windows applications using the platform bundle's link inputs.

Windows support libraries are built from Roc's startup sources and Zig's
compiler runtime and mingw-w64 import definitions. Native ring, SQLite, and zstd
dependencies use Zig's C compiler with the MSVC ABI. The bundle includes hashes,
source provenance, build commands, and original license notices for the shipped
Windows inputs, without copying Microsoft SDK or CRT archives.

This also fixes duplicate compiler builtin symbols that could prevent real
Windows applications from linking. New tests cover runtime initializers, TLS
callbacks, stack-cookie support, host linking, and TLS certificate acceptance
and rejection. Native C builds omit debug information unless requested, reducing
bundle size.

## Complete third-party notices

Release bundles now include the project's `LICENSE`, generated
`THIRD_PARTY_LICENSES.md`, and Rust standard-library notices. The generated
notices cover linked Cargo dependencies across all supported targets and record
the origins and hashes of prebuilt native inputs. Windows inputs retain their
own provenance inventory and original notices alongside these shared documents.

CI checks that generated notices remain current and rejects altered or
unrecorded Windows inputs. Redistributors should retain the bundled license and
provenance documents.

## Compiler compatibility

The platform and examples have been formatted with the new Roc formatter. The
generated Rust ABI glue is unchanged when regenerated with the pinned nightly
and its matching source.
