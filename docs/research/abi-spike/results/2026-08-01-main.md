# Generated callable wrappers on current Roc main

This run checks whether the compiler fix merged in Roc
`206f4c30b68ee6d02e1972828ee7b481ac8f23be` clears the retained-callable ABI
research blocker. The compiler was built from later main commit
`1c1ceccf672248bcd367cf3b21f4daadc0afd318`.

Environment:

- Linux x86-64, AMD Ryzen 7 9700X;
- Zig 0.16.0;
- generated C glue and x64 Linux musl host;
- development and speed backends; and
- benchmark pinned to logical CPU 2.

Correctness command:

```sh
ROC=/path/to/roc-main/zig-out/bin/roc \
ROC_SRC=/path/to/roc-main \
python3 scripts/spike_retained_callable.py \
  --opt all --iterations 1000 --mode wrapper
```

Both backends passed:

- non-recursive generated callable drop;
- recursive generated make, advance, and drop;
- parked and just-returned destruction;
- sequential migration across new pthreads;
- concurrent independent machines;
- host-side same-machine overlap rejection;
- cancellation during an in-flight hosted effect;
- nested strings, lists, records, and callable captures; and
- exact outer allocation and opaque-resource balance.

Both emitted:

```text
CORRECTNESS ok observed_calls=55 resource_allocations=8 resource_deallocations=8 max_independent=2
```

The development run ended with `14118` allocations and deallocations; speed
ended with `7163` of each. Both reported zero live allocations and zero
reallocations.

Pinned diagnostic command:

```sh
taskset -c 2 env \
  ROC=/path/to/roc-main/zig-out/bin/roc \
  ROC_SRC=/path/to/roc-main \
  python3 scripts/spike_retained_callable.py \
    --opt speed --iterations 1000000 --mode wrapper
```

The seven immutable-callable samples measured:

```text
109.793 109.979 109.926 110.270 109.968 109.980 109.498 ns/step
```

The median is 109.968 ns/step. Every sample requested exactly one allocation
and one deallocation per step. The fixture's atomic allocator ledger perturbs
allocation-heavy timing, so this is cost-class evidence rather than the final
controlled Go comparison.

Disassembly of the optimized generated drop wrapper reaches a helper which
loads and calls the erased callable payload's `on_drop` pointer before an
atomic outer decrement and 16-aligned deallocation. It no longer uses generic
box teardown.

Conclusion: the local generated-wrapper correctness blocker is cleared. The
callable candidate is available for continued transport and ergonomics
research, but immutable continuation replacement still fails the zero-hot-step
allocation requirement. Cross-target, native memory-instrumentation, and
controlled performance gates remain open before selecting the public ABI.
